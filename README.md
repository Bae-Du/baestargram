# baestargram

인스타그램 형태의 React 프론트엔드 프로젝트입니다.

## Stack

- React 19 + TypeScript
- Vite
- React Router

## 시작하기

```bash
npm install
npm run dev
```

## 스크립트

| 명령 | 설명 |
|------|------|
| `npm run dev` | 개발 서버 |
| `npm run build` | 프로덕션 빌드 |
| `npm run preview` | 빌드 미리보기 |
| `npm run lint` | 린트 |

## 페이지

- `/` — 홈 피드 (스토리 + 게시물)
- `/explore` — 탐색
- `/profile` — 프로필
- `/reels`, `/messages`, `/create` — 플레이스홀더
